# N.I.A Logo 金光与逐字动效设计

## 目标

在现有 N.I.A 紫色斜切转场中增强品牌感，同时保持画面简洁。仅新增两项关键运动：`NIA` 字形内部的金色扫光，以及 `NEXT IDOL AUDITION` 的逐字显现。

## 动效时间线

- 紫色 Logo 卡先淡入，`NIA` 主字随后稳定显现。
- `NIA` 字面横向扩展约 8%，取消当前负字距挤压，三个字之间使用轻微正字距；Logo 容器左右保留安全空间，任何支持的全屏比例下均不得裁切 `A`。
- 四角星芒使用内联 SVG 路径，不再使用 CSS `clip-path` 多边形。路径由四条圆弧内凹边围成饱满中心，主轴固定为右上—左下。轮廓必须关于这条斜轴严格镜像：左上与右下短射线等长，轴两侧的凹面控制点成对镜像；右上主射线最长、左下主射线次长，以保留原 PV 的切入方向感。
- 星芒使用纯亮黄 `#f3d900`，取消暖金渐变、描边和发光滤镜。最终尺寸约为 `NIA` 字高的 105%，允许主轴尖端明显超出字面。
- 星芒从画面右上安全区之外沿斜线快速切向 `I/A` 之间，轻微越过目标后回弹定住，再衔接主字内部的金色扫光。
- 主字出现约 0.15 秒后，一道窄幅、柔边、斜向金色高光由左向右扫过。
- 高光必须裁切在 `NIA` 字形内部，不得照亮卡片背景或形成外描边。
- 英文副标题紧随扫光开始，以约 25ms 的间隔从左到右逐字显现；空格保留排版宽度但不播放可见动画。
- 主视觉完整停留后，Logo 卡与所有内容共同淡出并打开 N.I.A 正式界面。
- 标准转场总时长约 1.6 秒；正式界面的打开时机位于退场阶段，避免提前遮住品牌画面。

## 实现边界

- 保留现有紫色斜切背景、四角星芒符号、全屏挂载与入口逻辑。
- 星芒使用用户提供的纯亮黄透明 PNG，保留其品牌符号身份和 `I/A` 交界处的最终中心位置。
- 星芒不得通过不对称微调模拟动势；方向感只由主轴两端的长度差与右上切入动画产生。
- 使用 HTML/CSS 原生动画，不引入动画库；字标与星芒使用用户提供的透明 PNG 资源。
- 英文副标题由同一字标 PNG 的 16 个裁切蒙版面板构成，CSS 根据顺序变量计算延迟。

## PNG 字标资源

- 主 `NIA` 使用用户提供的 `LOGO.png`，副标题使用 `NEXT_IDOL_AUDITION_纯白透明.png`；项目内分别保存为 `UI/nia-logo.png` 与 `UI/nia-subtitle.png`。
- 主图尺寸为 `512 × 512`，有效字形约位于 `X=60–438、Y=214–342`。副标题尺寸为 `2048 × 778`，有效字形约位于 `X=0–2008、Y=329–464`。两处均通过网页视口裁掉透明留白，不重采样原图。
- 主 LOGO 保持现有居中尺寸、入场节奏和字形内部金色扫光；扫光使用图片 Alpha 作为遮罩，不依赖浏览器字体。
- 副标题按 16 个可见字母建立独立 SVG 蒙版区域。所有蒙版都引用同一副标题图像坐标，相邻区域允许少量重叠以避免紧邻字母出现裂缝；空格只保留原图间距，不生成可见动画。
- 每个副标题字母继续按约 `25ms` 间隔淡入并轻微上移。黄色星芒、紫色斜切背景、整体淡入淡出、入口回调和减少动态效果保持不变。
- 扫光使用主字 PNG 的 Alpha 蒙版完成，不能改变 `NIA` 原有布局尺寸。
- 不恢复已删除的滑条、碎片或摄像机后拉效果。

## 无障碍与回退

- `prefers-reduced-motion: reduce` 下取消扫光移动及逐字错峰，主字和副标题直接淡入。
- 副标题的可访问文本仍应被连续读取，字符拆分节点对辅助技术隐藏，并提供完整标签。

## 星芒逐帧动画

- 本阶段只修改 `.nia-entry-logo-star` 及其叠层，不得给 `.nia-entry-logo-card` 或其他外层场景容器增加缩放、位移、旋转等镜头动画。后续镜头拉远必须作为独立阶段实施。
- 原 PV 为 30fps。用户提供的 8 张截图视为连续帧，相邻姿态间隔 `33.3ms`，从第一帧到第八帧共 `0.233s`。
- `0.15–0.383s` 依次复刻八个姿态：右上方纵向拉长切入、压缩为小星点并出现斜向残影、展开为完整长星芒、缩小至接近透明、完整闪现、降低透明度、恢复高亮、进入白色擦除状态。
- 星芒由四类共享同一 PNG 的层组成：黄色基础层、两层低透明度运动残影、白色擦除层和金黄色回填层。形变只使用 `translate`、`scaleX`、`scaleY` 与 `opacity`，不修改图片本身。
- `0.383–0.52s` 白色层沿星芒斜轴擦入，使黄色星芒变为白色；`0.52–0.88s` 金黄色层与主 `NIA` 扫光共用相同的时间进度，从白色擦回金黄色并保持到转场淡出。
- `prefers-reduced-motion: reduce` 下跳过逐帧位移、形变、残影与颜色擦除，星芒直接以最终金黄色显示。

## 独立镜头拉远

- 在 `.nia-entry-transition` 与 `.nia-entry-logo-card` 之间增加唯一的 `.nia-entry-camera` 取景层。镜头 transform 只能施加在该层，不得改写 `.nia-entry-logo-star`、主 LOGO 或副标题的局部 transform。
- 镜头采用中等强度方案：初始 `scale(1.5)`，以 `I/A` 与星芒交界处约 `55% 45.5%` 为变换原点，带轻微左下补偿和 `-1.2deg` 倾斜。
- `0.18–0.68s` 使用先快后慢的曲线拉远至 `scale(1)`，位移与倾斜同时归零；`0.68s` 后镜头保持稳定，不改变 1.6 秒总时长或 1.18 秒界面打开时机。
- `prefers-reduced-motion: reduce` 下 camera 直接处于最终 `scale(1)`、零位移、零旋转状态。

## 左侧整列渐变

- 删除当前以 `12% 50%` 为圆心的粉色 `radial-gradient`，不得再形成单点扩散亮斑。
- 背景改为贯穿全高的横向线性渐变：左边缘为粉紫色，前约 18% 保持整列明亮，`18–34%` 柔和过渡到主紫色，右侧继续过渡至现有深紫色。
- 本阶段不增加颗粒纹理或图片噪点，保持现有 UI 清晰度与资源体积。

## 验证

- 自动测试确认副标题字符结构、顺序变量、字内扫光关键帧、1.6 秒主时间线和减少动态规则存在。
- 自动测试确认主字与副标题引用同一 PNG、星芒引用独立透明 PNG、保留右上切入关键帧，并在减少动态模式下直接显示于最终位置。
- 运行 N.I.A 入口与启动器相关测试，并检查 JavaScript 语法与变更格式。
