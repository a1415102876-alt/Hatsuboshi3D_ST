# 五名担当偶像接入设计

## 范围

将仓本千奈、葛城莉莉娅、紫云清夏、有村麻央、姬崎莉波接入现有育成系统。五人进入担当选择、对话存档、行动提示词、随机互动避让、好感度剧情与 First Live 判定，不新增独立界面。

## 角色数据

采用用户提供的游戏截图数值，顺序均为 Vo / Da / Vi：

| 偶像 | 初始三维 | 成长率 |
| --- | --- | --- |
| 姬崎莉波 | 85 / 120 / 125 | 13 / 21.5 / 25.5 |
| 葛城莉莉娅 | 80 / 100 / 115 | 18 / 20 / 18 |
| 有村麻央 | 125 / 90 / 100 | 22 / 8 / 23 |
| 紫云清夏 | 100 / 115 / 90 | 9 / 23 / 23 |
| 仓本千奈 | 75 / 115 / 125 | 10 / 24 / 20.5 |

First Live 门槛与能力上限沿用现有角色的难度尺度，突出各自成长倾向，同时保证十八天流程可完成。

## 叙事配置

每名偶像配置角色核心，以及上课、训练、外出、交流和休息五类行动风格。内容从对应世界书与好感度剧情提炼，不复制完整原剧情。

- 千奈：能力不足、特权羞耻、想放弃却会回来完成下一步。
- 莉莉娅：零基础、自我否定、害羞但行动坚韧，把支持具体地还给观众。
- 清夏：轻佻懒散是保护色，围绕舞蹈创伤进行渐进恢复。
- 麻央：王子理想与身体变化冲突，最终容纳可爱、脆弱与帅气。
- 莉波：从刻意扮演姐姐转向自然照顾，也逐渐允许自己被照顾。

## 好感度路线

为每人补齐 0、20、40、60、80、100 六段剧情种子。0 建立担当关系；20 至 60 展开前十话中的核心矛盾；80 固定为 First Live 前夜；100 在演出成功后完成该篇章。种子只规定人物矛盾、关系转折和情景目标，具体对白与过程继续由 AI 生成。

## 验证

增加数据完整性检查，确认五名偶像均具备角色配置、十二项数值和六个好感度节点；运行 JavaScript 语法检查，并在担当选择界面验证五人可选且选择后数值正确。
