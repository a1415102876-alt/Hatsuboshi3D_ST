# N.I.A 平板宽屏放大设计

## 目标

在桌面浏览器全屏模式中，将 N.I.A 档案平板整体放大至当前视觉尺寸的 1.5 倍，提高档案文字和操作区域的可读性，同时保持现有平板内部排版、滚动距离和交互逻辑。

## 适配规则

- 仅在视口同时满足 `min-width: 1200px` 与 `min-height: 720px` 时启用 1.5 倍缩放。
- 宽屏状态下 `.tablet` 使用 `transform: translate(-50%, -50%) scale(1.5)`，并以中心为缩放原点。
- 不修改 `.tablet` 的基础 `610 × 780px` 最大尺寸，不放大内部字号、间距或页面宽高，避免档案内容重新排版。
- 小于宽屏断点时继续使用现有 `translate(-50%, -50%)`；`700px` 与 `430px` 移动端断点的宽高规则保持不变。

## 交互与边界

- 平板屏幕的原生滚动、鼠标拖动滚动、按钮、文本框和选择框继续使用现有 DOM 与事件处理，不增加 JavaScript 坐标换算。
- 宽屏缩放只影响渲染尺寸，平板仍固定在桌面中心，不改变背景装饰、返回按钮、全屏按钮或桌宠位置。
- 若视口高度不足 `720px`，不得强制 1.5 倍缩放，以免平板上下边缘和屏幕滚动区域被裁切。

## 验证

- 自动测试确认 `nia-prototype.css` 存在组合宽高媒体查询和精确的 `scale(1.5)` 变换。
- 自动测试确认基础、`700px` 与 `430px` 规则仍保留，且 JavaScript 滚动逻辑未修改。
- 运行 N.I.A 原型与宿主桥接相关测试，并执行 CSS 变更格式检查。
