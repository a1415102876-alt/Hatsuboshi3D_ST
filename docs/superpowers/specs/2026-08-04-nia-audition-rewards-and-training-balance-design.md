# N.I.A 试镜奖励与训练倍率设计

## 目标

第一轮试镜通过后提供明确的培养回报，同时提高 N.I.A 日程内训练的数值产出。奖励必须由前端确定、只结算一次，AI 只负责叙事。

## 试镜奖励

- 第一轮试镜固定增加 10,000 粉丝。
- Vo、Da、Vi 的基础奖励均为 120。
- 每项实际奖励为 `round(120 * (1 + 对应成长率 / 100))`。
- 成长率按非负百分比处理，缺失值视为 0。
- 属性增加后仍受偶像对应能力上限约束。
- 结算结果保存 `fanGain` 与 `statGains`，刷新恢复时沿用已保存结果。
- `progressionApplied` 保证确认结果只能应用一次。
- AI 输出中的 `fanGain` 或属性奖励不参与结算。

## N.I.A 训练倍率

- 仅当正式 N.I.A 训练状态处于 active 时，训练产生的 Vo、Da、Vi 增量乘 2。
- 倍率在现有成长率、角色训练倍率和 SP 加成计算完成后应用。
- 课程、休息、外出以及普通育成模式的训练不受影响。
- 最终属性仍按现有能力上限截断。

## 展示

试镜结果页同时显示第一名、10,000 粉丝以及三项实际属性增量。最终确认后刷新主界面能力值与 N.I.A 粉丝进度。

## 验证

- 纯核心测试覆盖固定粉丝、成长率换算与负值兼容。
- 流程测试覆盖一次性属性应用和 N.I.A 专属双倍训练。
- 运行全部 N.I.A 回归与 JavaScript 语法检查。
