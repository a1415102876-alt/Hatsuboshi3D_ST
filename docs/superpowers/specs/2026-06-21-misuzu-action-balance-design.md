# Misuzu Action Balance Design

## Goal

Make Hataya Misuzu's intended daily rhythm two productive actions plus one rest while keeping daily stat growth and net stamina cost close to three ordinary actions.

## Balance

- Lesson: primary stat +98, stamina -30, stress +1.
- Training: apply a 1.5 Misuzu multiplier to every normal training gain, then apply the existing 1.5 SP multiplier when active; stamina -33 and existing stress rules remain unchanged.
- Rest: stamina +30 and a 50% chance of a rest-specific random idol interaction using the existing reward pool.
- Existing lesson/training random-event chances remain 45% and 55%.
- No hard daily action limit is added.

## Interface

Misuzu's action cards display stamina -30 for lessons and stamina -33 for training. Other idols retain the existing labels and balance.
