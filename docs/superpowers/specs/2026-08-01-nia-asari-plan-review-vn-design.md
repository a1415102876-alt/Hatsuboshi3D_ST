# N.I.A 亚纱里老师企划评价 VN 设计

## 目标

点击“请亚纱里老师完善”后，继续使用现有 harness 的单次主模型请求。企划生成完成时先播放现有 VN 界面的亚纱里老师动态评价，评价播放结束后才将企划提交为完成状态，并返回 N.I.A 平板显示完善后的企划。

## 用户流程

1. 玩家提交完整企划草案。
2. N.I.A iframe 隐藏，宿主现有 VN 界面显示企划生成等待状态。
3. harness 返回合法的 `NIA_PLAN` 后，宿主解析并规范化企划，但暂不设置 `phase: plan_ready`，也暂不向 iframe 投影完善结果。
4. 宿主将 `asariReview.accepted`、`gap`、`advice` 转换为三段亚纱里老师 VN 台词；前置一段简短旁白，说明老师阅读企划草案。
5. 使用现有校园背景、亚纱里老师立绘、名字框、打字机、自动播放、日志与跳过控件播放评价。
6. 最后一段结束后，宿主将暂存企划正式提交为 `plan_ready / committed`，释放 N.I.A 企划会话状态，关闭 VN，并重新显示 N.I.A iframe。
7. iframe 接收正式状态同步，切换到已有的完善后企划界面。

## 状态与恢复

- N.I.A 状态增加可持久化的待评价企划字段；待评价阶段使用独立状态 `reviewing`，不得被投影为 `plan_ready`。
- harness 请求在 JSON 成功解析后即完成并释放主模型通道；VN 播放不继续占用主模型通道。
- 刷新后若发现合法的待评价企划，重新打开亚纱里老师评价 VN；不得静默跳过评价，也不得重新请求 API。
- VN 播放完成操作必须幂等。重复点击、跳过或恢复结束不得二次提交企划。

## VN 内容

- 旁白：亚纱里老师接过企划草案，逐页确认内容。
- 台词一：使用动态 `accepted`，先肯定玩家方向。
- 台词二：使用动态 `gap`，指出尚未解决的缺口。
- 台词三：使用动态 `advice`，说明完善方向并告知企划已整理完成。
- 缺失的单个评价字段使用简短本地回退台词；不得因字段为空阻止企划提交。
- 不发起第二次生成，不用固定台词替代已有动态评价。

## 错误处理

- API 请求失败或 `NIA_PLAN` 不合法时沿用现有可重试失败流程，恢复 N.I.A iframe，不打开评价 VN。
- VN DOM 不可用时直接执行同一个幂等提交函数，保证企划不会卡在 `reviewing`。
- 待评价数据损坏时清理待评价字段，并回到可重试失败状态。

## 验证

- 测试企划解析成功后进入 `reviewing` 而不是立即 `plan_ready`。
- 测试 VN 幻灯片使用亚纱里老师和三个动态评价字段。
- 测试 VN 播放结束后才提交企划、同步 iframe，并恢复可见性。
- 测试刷新恢复、重复完成幂等、无 VN DOM 回退和原有错误路径。
- 运行 N.I.A host bridge、企划 API 与 VN flow 相关测试。
