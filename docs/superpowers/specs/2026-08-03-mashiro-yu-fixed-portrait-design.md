# 真诚优固定立绘设计

## 目标

真诚优在所有支持角色立绘的场景中使用同一张正式立绘，包括《初星放送部》界面和普通 VN 对话。正式素材采用用户提供的 `E:\download\ChatGPT Image 2026年8月3日 21_58_27.png`。

## 素材与路径

- 将原图复制为 `assets/novel-standees/mashiro-yu.png`。
- 运行时代码只引用正式素材目录，不引用 `.superpowers/brainstorm` 下的设计草图资源。
- 现有 `assets/avatars/mashiro-yu.png` 继续仅作为小尺寸头像使用。

## 触发规则

- 标准角色名：`真诚优`。
- 兼容发言者名：`优`、`优前辈`、`Mashiro Yu`。
- 发言者名称按完整规范化结果匹配，不能在普通正文中做子串搜索。
- 上述名称统一解析为 `assets/novel-standees/mashiro-yu.png`。

## 使用范围

- VN 对话调用现有 `resolvePortraitForSpeakerVisualCue` 链路。
- 广播界面使用同一角色立绘映射，不另设一张主持人半身图。
- 广播列表、演员信息等小尺寸头像仍可使用头像资源，不属于立绘触发范围。

## 失败行为

正式立绘加载失败时，不回退到其他角色或旧立绘；当前立绘位置隐藏，并沿用现有图片错误处理记录失败 URL。

- 验证未知名称不会误触发真诚优立绘。
- 验证 VN 和广播代码都引用统一的正式素材路径。
- 验证正式 PNG 存在且与用户提供的原图内容一致。
