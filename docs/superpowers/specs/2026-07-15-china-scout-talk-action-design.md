# 千奈物色搭话按钮设计

## 目标

仓本千奈尚未接受担当、制作人正在仓本家卧室物色她时，角色操作弹窗不显示普通的“闲聊”“邀请同行”“询问想去哪”“查看状态”按钮，只显示一个“和千奈搭话”按钮。

## 状态边界

复用现有 `isChinaHomeScoutBedroomActive()` 判定。该判定要求当前处于沙盒物色阶段、目标是仓本千奈、场景是仓本家卧室，因此签约任务完成后不再成立。

非千奈物色状态保持现有角色操作菜单，包括千奈签约后的普通外出互动。

## 界面与交互

在角色操作菜单中新增一个默认隐藏的专用按钮，文案为“和千奈搭话”，并让它铺满操作区整行。

打开菜单时：

- 千奈物色状态隐藏四个普通按钮，显示专用按钮。
- 其他状态隐藏专用按钮，并按现有角色类型规则显示普通按钮。

点击专用按钮后关闭角色操作菜单，并调用现有 `startFreeModeOutingFacilityExplore("chat")`，进入完整的千奈物色剧情选择流程，而不是即时闲聊气泡。

## 验证

扩展现有校外场景测试，检查专用按钮、文案、整行布局、物色状态显隐切换和完整剧情路由。随后运行校外场景、沙盒物色、任务状态相关测试，以及 JavaScript 语法和差异检查。
