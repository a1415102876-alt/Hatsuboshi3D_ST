# N.I.A 档案页滚动企划草案设计

## 目标

保留 `idol-profile-standalone.html` 中平板内现有的偶像档案第一页，并在同一个平板屏幕内部增加可向下滚动进入的第二页“第一轮企划草案”。第二页采用已确认的“单页企划表”布局，与第一页保持一致的纸质学院档案风格。

本次只完成档案第一页与企划草案第二页的界面重构，为后续老师补全、五日日程和营业验证的统一 UI 重构建立视觉与结构基线。

## 范围

### 本次包含

- 将参考页中的平板、桌面背景和偶像档案第一页迁入现有 N.I.A 原型。
- 第一页保持现有资料内容、雷达图、报告和整体视觉结构。
- 在平板的 `.screen` 滚动容器中追加第二张纸页。
- 第二页承载现有草案阶段的三项输入：本轮目标、公众印象和实现方式。
- 保留“请亚纱里老师完善”动作、连接状态提示和当前企划编译 API 行为。
- 增加页码、分页线和“继续阅览 / 企划草案”滚动提示。
- 支持桌面端、窄屏和触控滚动，保留键盘可访问性与减少动态效果偏好。

### 本次不包含

- 不重构老师补全、五日日程和营业验证三个后续阶段的具体页面。
- 不修改 N.I.A 企划编译、宿主通信或业务 API 契约。
- 不改变草案字段含义、默认内容、校验规则或提交结果。
- 不增加横向翻页、3D 翻书或强制播放的过场动画。

## 页面结构

### 外层场景

外层继续使用参考页的桌面场景和固定平板。桌面本身不随内容滚动；唯一的主滚动区域是平板内部的 `.screen`。右侧说明栏和拖拽手柄继续保持隐藏，避免与 N.I.A 主流程竞争注意力。

### 第一页：偶像档案

第一页直接保留参考页的资料纸内容，包括头像、姓名、学院标识、五维雷达图和评价报告。第一页至少占据一个平板内容视口，使初次进入时不会露出第二页的表单主体。

第一页底部增加低调的继续提示，文案为“继续阅览 / 企划草案”。提示只负责说明内容方向，不作为唯一导航方式，也不阻断鼠标滚轮、触控滑动、触控板或键盘滚动。

### 第二页：单页企划表

第二页是一张独立的米白纸页，顶部使用档案编号和页码 `02`，主标题为“第一轮企划草案”。三项输入纵向排列：

1. 本轮希望达成的目标。
2. 希望观众如何认识偶像。
3. 准备通过什么方式实现。

字段使用始终可见的标签和纸面填写区，不用占位文本代替标签。底部保留连接状态与“请亚纱里老师完善”按钮。按钮视觉采用学院印章或档案确认章的语言，但必须保持清晰的按钮状态、焦点样式和足够对比度。

## 滚动与分页行为

- `.screen` 负责垂直滚动，平板外壳和外部桌面保持稳定。
- 第一、第二页之间使用纸张间隙、细分隔线和页码建立分页感。
- 使用轻度滚动吸附辅助用户抵达页首，但吸附不得强制抢夺滚动位置。
- 点击第一页底部的继续提示时，第二页页首平滑进入视口。
- 当系统启用 `prefers-reduced-motion: reduce` 时，取消平滑滚动和非必要过渡。
- 桌面鼠标拖拽滚动行为继续有效，触控设备使用原生纵向滚动。

## 视觉系统

第二页继承第一页的视觉语言：

- 米白色纸张与深灰绿色墨色。
- 珊瑚色用于装订线、状态标记和主要动作。
- 衬线字体用于标题与档案感较强的正文，中文无衬线字体用于表单标签和操作文本。
- 细线、编号、学院印章和小字号等宽字构成档案层级。
- 不沿用当前 N.I.A 原型的大面积蓝色卡片、圆角面板和仪表盘式顶部导航。

所有正文和表单文本保持可读对比度；正文不小于 14px，操作区域最小高度为 44px。可交互元素必须具有可见的悬停、焦点、禁用、加载和错误状态。

## 组件边界

- 桌面和平板外壳只处理场景与视口，不承载业务状态。
- 偶像档案页只显示资料，不修改现有 N.I.A 数据。
- 企划草案页复用现有的 `goalInput`、`imageInput`、`approachInput`、`apiStatus` 和 `compileBtn` 标识，避免破坏现有脚本绑定。
- 页面切换由滚动位置表达；草案提交仍由现有 JavaScript 业务函数触发。
- 后续阶段暂时保持现有行为，避免本次视觉试验扩大为完整流程重写。

## 错误与状态反馈

- 连接中、已连接和连接失败状态继续显示在提交区域附近。
- 独立打开时的 SillyTavern 连接警告保留，但视觉改造成档案告示，不遮挡第一页主要资料。
- API 错误不清空玩家输入，不自动跳转到后续阶段。
- 输入或提交失败时，焦点和错误说明保持在企划草案页内。

## 响应式与无障碍

- 窄屏时平板居中并限制在可视区域内，内部保持单列布局。
- 不产生页面级横向滚动；表单、图片和雷达图不得超出纸面。
- 所有标签与输入建立明确关联，按钮和滚动提示支持键盘操作。
- 保留语义标题层级、可见焦点环和足够的颜色对比度。
- 图片保留有意义的替代文本；装饰性桌面物件对辅助技术隐藏。

## 验证标准

- 初次进入只看到完整的偶像档案第一页和继续提示。
- 鼠标滚轮、拖拽、触控滑动和键盘滚动均可到达第二页。
- 点击继续提示能到达企划草案页首；减少动态效果模式下不会播放平滑滚动。
- 三个输入字段保留默认内容，可正常编辑，并能触发现有企划编译流程。
- 连接状态、独立模式警告、加载、错误和禁用状态仍能正确显示。
- 桌面和移动视口均不存在横向溢出、元素重叠、破图或控制台错误。
- 既有 N.I.A 单元测试继续通过，并新增针对两页结构和关键标识保留的测试。

## 后续方向

本次验证通过后，老师补全、五日日程和营业验证页面将分别作为后续纸页接入同一个平板滚动档案体系；具体布局需另行确认，不在本规格中预设。
