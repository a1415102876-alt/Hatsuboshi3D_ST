# 换日场景同步与世界引擎手动推演设计

日期：2026-07-13

状态：已确认

## 目标

1. 玩家在制作人公寓通过时间管理进入下一天后，地图、公寓、日期与操作入口立即显示新一天状态。
2. 在“初星世界引擎”手机应用中提供“手动推演本日走向”入口，供自动日切未产出、失败或用户希望重算时使用。

## 根因与修复边界

`advanceFreeModeToNextDay()` 已正确更新并保存 `state.freeMode.postLiveDay` 与 `clockMinutes`，但结束时只调用 `renderFreeModeStage()`。当换日前位于制作人公寓时，公寓舞台仍保留旧 DOM 和可见状态，直到后续完整 `render()` 才恢复一致。

修复只把换日后的局部地图渲染改为完整渲染。不得修改换日数值、世界日切、任务日切、Director job 准备顺序或随机结果。

## 手动推演入口

世界引擎应用增加固定底部操作按钮“手动推演本日走向”。它直接调用现有 `requestManualWorldDirectorRecalculation()`，保留以下既有规则：

- 世界导演必须启用；
- 主模型与次模型通道必须空闲；
- 次 API 必须已配置；
- 用户需要确认重算；
- 只更新 `DailyDirection` 与 `DramaPressure`，不修改数值、时间或随机结果。

按钮在 Director job 为 `generating` 或 `validating`，或任一模型通道被占用时禁用并显示“正在推演…”。点击后立即刷新世界引擎应用，使运行状态可见。刷新图标仍只读取并刷新界面，不发起生成。

## 验收

- 从制作人公寓推进至 22:00，再点击进入下一天，公寓应立即退出，地图显示第二天 08:00，无需重进页面。
- 自动日切链路顺序保持“公开世界层 -> Director 准备/请求”。
- 世界引擎应用任一标签页均可看到手动推演按钮。
- 手动按钮沿用既有确认、配置检查和通道门禁；不得建立第二套 Director 请求流程。
