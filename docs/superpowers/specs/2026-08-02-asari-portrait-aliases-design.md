# 亚纱里老师立绘别名适配

## 目标

让 VN 对话中的 `亚纱里老师`、`亚纱里`、`根绪亚纱里` 都触发现有的亚纱里老师立绘，并共享同一个角色键与换装状态。

## 设计

在说话人立绘解析边界增加独立的 NPC 别名表，不修改偶像别名表，也不复制 `vnStandees` 资源项。

别名映射：

- `亚纱里老师` -> `亚纱里老师`
- `亚纱里` -> `亚纱里老师`
- `根绪亚纱里` -> `亚纱里老师`

`resolvePortraitForSpeaker` 在解析非偶像 NPC 立绘前先规范化 NPC 名称。三个输入最终都解析为：

- 角色键：`npc:亚纱里老师`
- 默认资源：`./assets/novel-standees/asari-sensei.png`

原始说话人文本继续用于姓名框显示，不改写 AI 输出或剧情正文。

## 边界

- 不改变 `canonicalIdolName` 和偶像选择逻辑。
- 不为三个别名创建独立换装槽位。
- 不做模糊匹配，避免包含“亚纱里”的其他文本误触发立绘。
- 未知 NPC 仍不显示立绘。

## 验证

扩展现有立绘集成测试，分别验证三个称呼都返回 `npc:亚纱里老师` 和同一默认立绘；同时保留未知老师无立绘的回归检查。
