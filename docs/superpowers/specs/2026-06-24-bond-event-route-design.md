# 羁绊事件长线叙事设计草案

## 目标

羁绊事件不再只是一次性短叙事，而是承担每个偶像个人问题与核心矛盾的阶段性推进。

前端仍然保留现有的好感度节点：

```text
0 / 20 / 40 / 60 / 80 / 100
```

但每个节点内部可以按原作好感剧情的大纲与情绪结构，改造成带 1-2 次玩家选择的长线叙事。

## 设计判断

不建议把 First Live 阶段的原作 10 话剧情直接拆成 10 个前端按钮。

原因：

- 18 天育成节奏会被剧情按钮打散。
- 玩家会从“育成中自然推进关系”变成“点剧情列表”。
- 每个节点都要等待 AI 回复，10 话会显著拖慢流程。
- 世界书、前端、存档与 UI 维护量都会翻倍。

推荐方案是：

```text
外显节点：0 / 20 / 40 / 60 / 80 / 100
内部结构：吸收原作 10 话大纲
```

也就是“五话外显，十话内核”。

## 原作 10 话到前端节点的默认映射

```text
好感度 0：
对应原作 1 话。建立担当关系，提出第一矛盾。

好感度 20：
对应原作 2-3 话。早期训练、相互试探、为什么选择她。

好感度 40：
对应原作 4-5 话。核心问题暴露，第一次明显动摇或破防。

好感度 60：
对应原作 6 话或 6-7 话。开始主动改变，制作人关系转折。

好感度 80：
对应原作 7-8 话或 8-9 话。路线后半转折、旧关系回收、Live 前课题确认。

好感度 100：
对应原作 9-10 话或 10 话。Live 成功后收束，角色回答最初的问题。
```

这不是强制模板。剧情密度较高的角色可以按原作节奏定制映射。
例如手毬路线更适合：

```text
60：第 6 话，首场 Live 失败与能力波动分析。
80：第 7-8 话，制作人依赖、美铃视角、SyngUp 重组提案与下场 Live 赌约。
100：第 9-10 话，Live 成功后与美铃和解，完成 First Live 篇章收束。
```

## 羁绊事件的新结构

每个羁绊事件推荐最多 2 次选择、3 段叙事：

```text
羁绊事件开始
→ AI 写开场：当前矛盾浮现
→ 选项 1：选择突破方向
→ AI 写中段：角色尝试，暴露更深层问题
→ 选项 2：选择制作人如何介入 / 角色如何面对
→ AI 写收束：完成本节点突破
```

普通行动的选项可以随机生成，但羁绊事件的关键选项应该尽量定制。

原因是羁绊事件承担角色主线，如果选项完全交给 AI 随机生成，容易偏离原作大纲或把角色矛盾写散。

## 数据设计建议

后续前端可以引入 `bondRoutes` 或类似结构：

```js
bondRoutes: {
  "月村手毬": {
    20: {
      title: "相互试探",
      objective: "分析手毬状态下滑的原因，并确立制作人成为新同伴的关系。",
      canonAnchor: "胖了、报复性节食、组合解散、失去燐羽和美铃的支撑、重新说出顶级偶像目标。",
      phase1Choices: [],
      phase2Choices: [],
      resolution: "改善饮食计划成立，制作人承诺托住她，手毬重新说出成为顶级偶像的目标。"
    }
  }
}
```

如果某个偶像或节点暂时没有定制数据，可以退回当前的一次性好感剧情生成。

推荐渐进式改造：

```text
第一阶段：只做月村手毬 20
第二阶段：补十王星南 20
第三阶段：整理每个偶像 20/40/80 的关键节点
第四阶段：决定是否把 60/100 也改为多轮
```

## 十王星南方向草案

星南好感度 20 的主题可以是：让她挑战过去不会做、也不擅长的事情。

节点目标：

```text
她已经是学园顶点，但过去的训练无法让她继续成长。
制作人让她尝试不符合完美学生会长形象的挑战。
她第一次体验“不完美但有变化”。
```

第一轮选项：挑战什么

```text
1. 让她在商店街即兴叫卖
2. 让她接受粉丝随机提问
3. 让她和低年级学生一起做基础练习
4. 让她在小舞台表演完全不优雅的角色
```

第二轮选项：怎么面对狼狈

```text
1. 继续维持完美姿态
2. 承认自己不擅长，但继续做完
3. 把失败包装成表演
4. 主动向观众询问反馈
```

收束方向：

```text
星南不是因为完成得漂亮而成长，
而是第一次承认“我也可以用不完美的方式被看见”。
```

## 月村手毬好感度 20 草案

### 原作大纲锚点

手毬的好感度 20 对应原作 2-3 话的大致内容：

```text
制作人分析手毬目前状态不好的原因。
原因之一是她胖了，并且因为害怕变差而报复性节食。
因此首先要改善饮食。
随后手毬向制作人倾诉另一个原因：
自己的组合已经解散，没有燐羽和美铃托住自己。
制作人表示自己能够成为手毬新的同伴，帮助她成为顶级偶像。
手毬也重新说出自己的目标：成为顶级偶像。
```

这个节点的核心不是“体重管理”，而是：

```text
状态变差
→ 她用错误方式惩罚自己
→ 组合解散后没人托住她
→ 制作人提出成为新的支撑
→ 她重新说出顶级偶像目标
```

### 节点目标

```text
分析手毬状态下滑的原因，并建立“制作人作为新同伴托住她”的关系。
```

### 第一轮选项：制作人先指出什么问题

这轮发生在训练后。手毬表现差、体力不稳、情绪烦躁，制作人要选择从哪个切口进入她的防线。

```text
1. 直接指出她体重和体力管理出了问题
2. 先问她最近有没有好好吃饭
3. 从训练录像里指出她动作变钝的原因
4. 不谈体重，先说“你现在像是在惩罚自己”
```

选项语气差异：

```text
1：最直接，容易激怒她，但最快切中问题。
2：更温和，容易让她嘴硬。
3：更专业，适合制作人以观察力进入。
4：最接近核心，直接指向报复性节食和自我厌恶。
```

第一轮中段必须推进到：

```text
她胖了。
她害怕变差。
她开始报复性节食。
制作人指出必须改善饮食，不能用惩罚自己的方式训练。
```

### 第二轮选项：组合解散后，制作人如何回应

这轮发生在手毬说出没有燐羽和美铃托住自己之后。

```text
1. “那从今天开始，我来托住你。”
2. “你不需要回到以前的组合，也能重新成为顶级偶像。”
3. “燐羽和美铃不在，不代表你只能一个人摔下去。”
4. “如果你还想成为顶级偶像，就把这个目标重新说出口。”
```

选项情绪差异：

```text
1：建立制作人作为新同伴的关系。
2：强调从过去组合里独立出来。
3：承认失去支撑的痛。
4：逼她重新确认目标。
```

### 收束要求

```text
改善饮食计划成立。
制作人承诺成为她的新同伴。
手毬别扭但认真地说出目标：她要成为顶级偶像。
```

推荐的最强路线：

```text
第一轮选项 4：你现在像是在惩罚自己。
第二轮选项 1：从今天开始，我来托住你。
```

这条线最贴近手毬：

```text
她表面冷硬，实际上需要有人精准指出她不是“不努力”，而是把努力变成自伤；
随后再给她一个新的支撑点。
```

## 月村手毬好感度 40 草案

### 原作大纲锚点

手毬好感度 40 可以吸收原作 4-5 话。

第 4 话偏核心问题解析：

```text
制作人邀请手毬讨论训练计划。
手毬看到制作人房间或墙面上贴满自己的照片，被吓到并误会。
手毬进一步讲述 SyngUp 时期的事情：
燐羽和美铃为了配合手毬，曾经故意压制自己的实力。
制作人指出，手毬注意力越集中，越能发挥实力，但体力也越容易迅速燃尽。
燐羽和美铃正是因为明白这一点，才压制自己、托住节奏，让她能把歌唱到最后。
手毬因此感到愧疚，觉得自己拖了后腿，也受不了两人的善意，于是单方面退出组合。
制作人提出训练目标：
作为单人偶像活动，克服弱点，锻炼到能靠自己唱完为止。
```

第 5 话偏日常关系缓和：

```text
制作人为帮手毬克服弱点而给她录像。
手毬因为之前看到一整墙照片，误会制作人又在拍她照片。
她觉得被拍下来很害羞，于是任性地想报复，也拿手机拍制作人照片。
结果她上课时偷偷看制作人照片傻笑，被老师发现并没收手机。
制作人被亚纱里老师叫到办公室询问原因，最后好不容易解释清楚。
```

这两话虽然信息量大，但可以整合成同一天内的一个节点：

```text
上午/训练前后：讨论训练计划，揭开 SyngUp 退队真因。
下午/课堂日常：录像误会与手机事件，表现手毬孩子气、任性、害羞的一面。
```

### 节点目标

```text
揭示手毬真正的问题不是实力不足，而是高集中输出会快速燃尽体力；
同时揭示她退出 SyngUp 的根本原因是愧疚与无法承受同伴善意。
最后用日常误会让关系从沉重剖析中稍微变软，表现她仍然孩子气、任性、容易害羞。
```

### 结构建议

好感度 40 可以做成“严肃剖析 + 日常破冰”的两段式节点。

第一段必须承担核心解释：

```text
制作人拿训练录像或资料解释她的弱点：
她集中时唱得极强，但体力燃尽太快。
燐羽和美铃过去不是看不起她，而是在压制自己配合她，让她能完成整首歌。
手毬因此意识到自己的愧疚与退队理由被制作人看穿。
```

第二段转入日常误会：

```text
制作人继续为了训练录像。
手毬误会成拍照收藏，害羞、炸毛、任性报复。
手机照片事件把沉重关系短暂拉回日常。
```

### 第一轮选项：制作人如何揭开 SyngUp 的真相

```text
1. 直接播放训练录像，对比手毬集中前后的体力消耗
2. 先问她为什么认为燐羽和美铃是在“迁就”自己
3. 用数据说明她不是实力不够，而是输出方式太极端
4. 直接指出她退出组合不是因为讨厌两人，而是受不了善意
```

选项语气差异：

```text
1：最专业，适合从训练计划自然切入。
2：让手毬自己说出愧疚，情绪更细。
3：把问题从人格否定转成可训练弱点。
4：最尖锐，容易让手毬破防。
```

第一轮中段必须推进到：

```text
手毬承认 SyngUp 旧事仍然刺痛她。
制作人说明燐羽和美铃压制实力，是为了让她能把歌唱到最后。
手毬不是没有才能，而是需要学会单人活动时分配体力和控制输出。
```

### 第二轮选项：训练目标如何落地

```text
1. 制作人提出从体力分配训练开始，先做到完整唱完一首歌
2. 制作人提出录像复盘，把燃尽的瞬间一帧一帧找出来
3. 制作人要求她不要再把同伴的善意当成羞辱
4. 制作人让她亲口说出：这一次要作为单人偶像唱到最后
```

第二轮后可以自然接入第 5 话的日常桥段：

```text
如果选择 2，录像误会会更顺。
如果选择 1 或 4，录像可以作为训练记录工具出现。
如果选择 3，日常误会可以缓和刚才过于尖锐的气氛。
```

### 日常桥段收束

```text
制作人为了训练录像。
手毬误会制作人在偷拍或收集照片。
她害羞又不服气，拿手机拍制作人作为报复。
课堂上看照片傻笑被老师发现，手机被没收。
制作人被亚纱里老师叫去解释。
这段不要写成恋爱告白，而是写成手毬孩子气、任性、嘴硬、关系逐渐变近。
```

### 收束要求

```text
制作人与手毬确立新的训练目标：
她要作为单人偶像，克服体力燃尽和输出失控的问题，锻炼到能靠自己唱完。
她对燐羽和美铃的愧疚不能立刻解决，但开始愿意把问题交给制作人一起处理。
日常误会让沉重的旧组合话题没有停在自责里，而是留下关系变柔软的余温。
```

### 设计备注

手毬的好感剧情信息量很大，不一定每个节点都能完整压缩两话。

但 4、5 话发生在同一天，并且一个严肃、一个日常，组合起来有叙事节奏：

```text
核心问题暴露
→ 训练目标成立
→ 日常误会破冰
```

因此可以作为好感度 40 的一个长线羁绊事件。

## 月村手毬好感度 60 草案

### 原作大纲锚点

手毬好感度 60 可以吸收原作第 6 话。

第 6 话的核心内容：

```text
手毬举办首场 Live。
彩排时她用力过猛，正式上场时已经没有足够体力。
结果 Live 失败。
制作人据此分析出：
手毬的实力非常容易受感情影响。
她的上限很高，但下限也很低。
今后的训练目标不是压低上限，而是让她能稳定发挥，并充分利用她的上限。
```

### 节点目标

```text
让手毬第一次以单人偶像身份面对失败。
失败不是否定她的才能，而是暴露她的波动性：
感情越高涨，爆发力越强，但体力与稳定性越容易崩坏。
制作人需要把“她会失败”改写成“她拥有极高上限，因此需要学会稳定触发上限”。
```

### 结构建议

好感度 60 不适合写成日常插曲，而应该是一次小型 Live 失败回。

```text
开场：首场 Live 前，手毬因紧张和兴奋，在彩排中过度投入。
中段：正式演出时体力不足，声音、呼吸或动作出现明显失误。
收束：制作人分析失败原因，指出她不是没有实力，而是感情影响导致上限和下限落差过大。
```

这段的重点不是“安慰失败”，而是把失败转化为下一阶段训练逻辑。

### 第一轮选项：制作人如何处理彩排用力过猛

```text
1. 立刻中止彩排，要求她保存体力
2. 记录彩排中爆发最好的一瞬间
3. 不打断她，先观察她为什么停不下来
4. 告诉她真正的舞台不是彩排，必须把热量留到正式演出
```

选项语气差异：

```text
1：制作人更强硬，容易激起手毬反抗。
2：制作人看见了她的上限，适合后续分析。
3：制作人更冷静，强调观察波动原因。
4：直接点出她无法分配感情和体力。
```

第一轮中段必须推进到：

```text
手毬在彩排中表现出惊人的瞬间爆发。
但也因此消耗过度。
她嘴上不承认，身体却已经明显疲惫。
```

### 第二轮选项：Live 失败后，制作人如何定义这次失败

```text
1. “失败不是因为你弱，而是因为你的上限太高，身体追不上。”
2. “你需要学会把感情留到最该燃烧的地方。”
3. “今天不是终点，是我们第一次看清你的波动幅度。”
4. “我要训练的不是平均的你，而是能稳定到达最高点的你。”
```

第二轮收束必须推进到：

```text
手毬承认自己无法稳定控制状态。
制作人确认今后的训练目标：
不是让她变得普通、保守或压低输出，
而是让她能够在正式舞台上充分发挥自己的上限。
```

### 收束要求

```text
Live 失败必须被明确写出，不要改成侥幸成功。
手毬可以嘴硬、沮丧、愤怒，但不能彻底放弃。
制作人必须把失败转译成可训练的课题：
感情影响强、上限高、下限低、需要稳定发挥。
```

## 月村手毬好感度 80 草案

### 原作大纲锚点

手毬好感度 80 可以吸收原作第 7-8 话。

第 7 话不是第 6 话的同日后续，而是下一段关系线的开端：

```text
手毬给制作人打电话。
她因为制作人没有立刻接电话而不满，又小心确认制作人是不是在生气。
这段表现手毬对制作人的依赖逐渐增强。
随后制作人初遇美铃。
美铃关心手毬的生活、饮食、房间、起床状态，也看过手毬失败的 Live。
美铃认为手毬一个人不行，拜托制作人成为 SyngUp 的制作人。
```

第 8 话直接承接第 7 话：

```text
美铃希望制作人帮助 SyngUp 重新集结。
制作人拒绝这个提案。
手毬因为联系不上制作人一路找过来，撞见制作人与美铃谈话。
美铃公开提出重组 SyngUp。
制作人指出：手毬并不适合单人活动，但也完全不适合团体活动。
她需要的不是回到原组合，而是找到能托住她、又能让她发挥上限的方式。
制作人以“下场 Live”为赌约：
如果美铃看完后仍然担心，就接受 SyngUp 制作人的提议；
如果美铃输了，就要和手毬找时间好好谈谈。
```

因此好感度 80 的关键词可以是：

```text
依赖、担心、美铃视角、SyngUp 重组提案、拒绝回到过去、下场 Live 赌约。
```

### 节点目标

好感度 80 的功能不是“舞台前夜”，而是把手毬的个人路线推到最终验证前。

```text
60 的失败让制作人看清了手毬的能力波动。
80 则让美铃重新进入主线，让旧组合关系从“手毬的内疚”变成现实中的对话对象。
制作人需要同时回应两件事：
一是手毬确实越来越依赖自己；
二是美铃对手毬的担心并不是错的，但解决方法不应只是回到 SyngUp。
```

这个节点的核心不是让 SyngUp 立刻复活，而是建立一个更强的目标：

```text
让手毬用下一场 Live 证明：
她不是只能被旧同伴托住的人。
她也不是必须回到过去才能继续唱下去的人。
现在的她可以在制作人的支持下，向美铃展示新的可能性。
```

### 结构建议

好感度 80 可以写成“电话依赖 + 美铃会谈 + 赌约成立”的长线事件。

```text
开场：手毬不断打电话，表现她对制作人的依赖与不安。
中段：制作人遇见美铃，美铃从生活与旧同伴视角谈手毬。
冲突：美铃提出重组 SyngUp，手毬赶到并听见。
收束：制作人拒绝简单重组，以下一场 Live 作为赌约，让美铃见证手毬的改变。
```

### 第一轮选项：制作人如何回应手毬的电话依赖

```text
1. 先接电话，告诉她自己正在处理她的负面传闻
2. 故意晚一点回拨，观察她为什么这么不安
3. 直接问她是不是害怕自己生气
4. 让她稍后当面来谈，不在电话里继续绕圈
```

选项语气差异：

```text
1：制作人主动安抚，强化信赖。
2：制作人更冷静，凸显手毬依赖过深。
3：直接点破不安，适合推进关系。
4：把问题导向当面沟通，方便后续撞见美铃。
```

第一轮中段必须推进到：

```text
手毬表面不讲理，实际在确认制作人是否还站在自己这边。
制作人意识到，60 之后她不只是信任自己，而是开始依赖自己。
```

### 第二轮选项：面对美铃的 SyngUp 重组提案

```text
1. 直接拒绝：手毬不能靠回到过去解决现在的问题
2. 先承认美铃的担心，再指出重组不是唯一答案
3. 要求美铃看完手毬下一场 Live 后再判断
4. 当着手毬的面说明：现在托住她的人会是制作人
```

选项语气差异：

```text
1：强调断开过去。
2：照顾美铃立场，关系更柔和。
3：最适合原作赌约结构。
4：强化制作人与手毬的搭档关系，但要避免写成排斥美铃。
```

第二轮收束必须推进到：

```text
美铃没有被否定，她的担心被承认。
手毬也没有被简单塞回 SyngUp。
制作人提出以下一场 Live 作为验证：
如果手毬不能让美铃放心，就重新考虑美铃的提案；
如果手毬做到了，美铃就要和手毬好好谈谈。
```

### 收束要求

```text
不要让 SyngUp 在好感度 80 直接重组。
不要把美铃写成阻碍手毬成长的人。
不要把手毬对制作人的依赖写成成熟稳定的信赖；她此时仍然很别扭、任性、怕被丢下。
结尾必须形成“下场 Live 赌约”，为好感度 100 的第 9-10 话收束铺路。
```

### 与好感度 100 的衔接

好感度 100 可以承接原作第 9-10 话：

```text
第 9 话前半：Live 登场前。
第 9 话后半：Live 成功之后。
第 10 话：Live 结束后与美铃修复关系，并进入手毬和制作人的交心。
```

其中第 9 话的“Live 登场前”不适合完全放进好感度 100。
因为前端本来就有 First Live 登场前 / 演出中的环节，所以这部分更适合作为 First Live prompt 的角色专属种子：

```text
手毬在登场前想起与美铃的赌约。
她担心自己是否真的能赢、是否真的能让美铃放心。
她确认制作人是否还愿意继续支持自己，甚至担心制作人会不会厌烦 SyngUp 的麻烦。
制作人需要把她拉回舞台，提醒她这次要发挥全部实力。
```

好感度 100 则只在 First Live 成功后解锁，正好承接第 9 话后半和第 10 话：

```text
Live 成功后，美铃见证手毬的改变。
手毬与美铃终于把过去没说出口的话说出来。
美铃不再只是“托住手毬的人”，手毬也不再只是“被同伴照顾的人”。
二人关系得到修复，但不必立刻回到 SyngUp 原状。
最后进入手毬与制作人的交心：
制作人不只是替代 SyngUp，而是帮助手毬重新理解同伴、舞台和自己的才能。
First Live 篇章以“手毬能唱到最后，也能重新面对旧同伴”收束。
```

因此手毬的最终衔接应写成：

```text
好感度 80：成立下场 Live 赌约。
First Live 登场前：引用第 9 话前半作为专属演出前种子。
First Live 成功：解锁好感度 100。
好感度 100：第 9 话后半 + 第 10 话，完成美铃关系修复与制作人交心。
```

## 月村手毬好感度 100 草案

### 原作大纲锚点

好感度 100 只在 First Live 成功后解锁，因此不需要再从演出前开始写。

第 9 话可以拆成两部分：

```text
演出前：手毬确认与美铃的赌约，担心自己能否让美铃放心。
演出后：Live 成功，手毬发挥全部实力，美铃见证她的改变。
```

其中“演出前”应作为 First Live 专属种子，不放进好感度 100。
好感度 100 从 Live 成功后的后台开始。

第 9 话后半的核心：

```text
手毬筋疲力尽，但完成了能让人看见上限的 Live。
美铃仍然担心她会燃烧到自毁，却也承认这就是手毬自己的节奏。
手毬和美铃互相道歉。
两人承认已经无法像过去那样一起唱歌。
手毬说自己和美铃在一起会向她撒娇，所以不能回到以前的形式。
美铃把手毬托付给制作人。
手毬明确表示制作人是只属于自己的制作人。
```

第 10 话的核心：

```text
手毬与美铃搬到双人房间，关系明显修复。
两人仍然会拌嘴、较劲、互相吃醋，但气氛已经不是决裂，而是亲近。
美铃提出如果制作人愿意，也可以成为她和手毬共同的制作人。
手毬强烈反对，暴露她对制作人的独占欲与依赖。
之后手毬与制作人单独散步。
手毬承认：即使不能再和美铃站在同一个舞台上唱歌，她们也可以继续做朋友。
她向制作人道谢，并说出自己成为偶像的根源。
```

### 节点目标

好感度 100 的目标不是单纯庆祝 Live 成功，而是完成手毬 First Live 篇章的三个闭环：

```text
1. 与美铃修复关系：
   从“被同伴托住所以痛苦”变成“可以不回到过去，也能重新做朋友”。

2. 与制作人确认关系：
   制作人不是 SyngUp 的替代品，而是能陪她走到最高峰的人。

3. 与自我厌恶和解：
   手毬承认自己过去讨厌那个懒散、脆弱、爱撒娇的自己。
   但她也承认，正因为每天都痛苦地努力追赶憧憬，自己才有魅力。
```

### 剧情种子定位

```text
Live成功后：赌约兑现、美铃放手、关系修复、不能回到过去、只属于自己的制作人、成为偶像的根源、人工翅膀、陪我到最高峰。
```

可写进 AIRP / 世界书的简短种子：

```text
First Live 成功后，美铃见证手毬真正全力的舞台。手毬与美铃互相道歉，承认无法回到过去的 SyngUp，但可以重新成为朋友。美铃把手毬托付给制作人。之后手毬向制作人说出自己成为偶像的根源：她讨厌过去懒散、脆弱、爱撒娇的自己，所以追逐顶级偶像，想成为能让自己也喜欢上的存在。制作人确认自己选择的正是这个靠痛苦努力长出人工翅膀的手毬。结尾停在手毬邀请制作人陪她一起去最高峰。
```

### 结构建议

好感度 100 可以分成两段，而不是再做复杂多轮选择：

```text
第一段：后台 / Live 后休息室
美铃进入，兑现好感度 80 的赌约。
手毬、美铃、制作人三方完成关系修复。

第二段：搬家后 / 校园散步
手毬和美铃恢复朋友关系。
手毬与制作人单独交心，说出成为偶像的理由。
```

如果仍然想保留玩家选择，建议只放一轮轻选择，避免破坏结局节奏。

### 可选的一轮选项：制作人如何回应手毬的确认

```text
1. “我选择的是现在这个会痛苦、会任性、但仍然向最高峰伸手的你。”
2. “你不是天生的天才，所以你每天继续努力的样子才最有魅力。”
3. “人工的翅膀也能飞。只要你愿意，我会陪你调整到最后。”
4. “我会陪你到最后一刻。不是作为 SyngUp 的替代，而是作为你的制作人。”
```

这轮选项不应该改变结局，只改变制作人回应的侧重点。

### 收束要求

```text
必须发生在 First Live 成功之后。
不要把美铃写成输家，也不要把手毬写成彻底摆脱美铃。
不要让 SyngUp 立刻重组。
不要把手毬的独占欲写成成熟告白；它仍然带着任性、依赖和孩子气。
必须写出手毬成为偶像的根源：讨厌过去的自己，所以追逐顶级偶像，想成为能喜欢自己的存在。
制作人的回应必须确认：她不是超人，也不是天生天才，但她痛苦地努力、踮脚追逐憧憬的样子正是魅力所在。
结尾停在“陪她去最高峰”的闭幕感。
```

## 关于好感度 80 与舞台前夜的设计冲突

目前前端把好感度 80 固定为“舞台前夜”。

但手毬路线显示出一个问题：

```text
原作后半还有第 7、8、9 话的连续剧情。
如果好感度 80 被固定成舞台前夜，
第 7 话开始的美铃 / SyngUp 关系线会很难自然展开。
```

因此需要重新考虑 80 的定位。

### 方案 A：保留 80 为舞台前夜

优点：

```text
结构简单。
所有偶像统一。
First Live 前有固定情绪准备。
```

缺点：

```text
会挤压手毬这种后半剧情较多的角色。
第 7、8 话很难放进 60 和 80 之间。
羁绊剧情容易被迫跳跃。
```

### 方案 B：舞台前夜单独作为系统事件

推荐。

```text
好感度 80 不再固定等于舞台前夜。
好感度 80 改成“最终羁绊节点”或“路线后半转折”。
舞台前夜作为 First Live 前一天的系统强制事件独立触发。
```

优点：

```text
每个偶像可以保留自己的后半剧情节奏。
舞台前夜不再抢占角色路线节点。
手毬第 7-8 话可以自然接到好感度 80。
所有角色仍然可以拥有统一的 First Live 前夜事件。
```

缺点：

```text
前端机制要多一个“舞台前夜事件”。
总天数和羁绊事件日机制需要一起调整。
```

### 方案 C：增加羁绊事件数量

例如：

```text
0 / 20 / 35 / 50 / 65 / 80 / 95 / 100
```

优点：

```text
能更细地贴合原作 10 话。
```

缺点：

```text
UI、数值、世界书触发、剧情等待次数都会变复杂。
玩家可能被羁绊事件打断过多。
```

### 当前倾向

暂定推荐方案 B：

```text
羁绊事件仍使用 0 / 20 / 40 / 60 / 80 / 100。
好感度 80 改为角色路线后半最终转折。
舞台前夜从羁绊事件中剥离，作为 First Live 前一天的独立系统事件。
```

配合之前讨论的日程调整：

```text
总天数从 18 增加到 23。
达到羁绊阈值后的下一天强制进入羁绊事件日。
舞台前夜作为 Day 22 或 First Live 前一天的强制事件。
Day 23 进入 First Live。
好感度 100 在 First Live 成功后作为结局事件触发。
```

## 羁绊事件日机制草案

### 设计目的

羁绊事件往往需要完整讲完一个情景，不适合和当天的上课、训练、外出叙事混在一起。

如果继续让玩家在同一天既训练又触发羁绊事件，AI 很容易把时间线写乱：

```text
上午训练
下午羁绊事件
晚上又回到训练结果
```

这样会削弱每个偶像的个人主线。

### 推荐规则

```text
总日程：23 天。
常规育成日：每天 3 次普通行动 + 1 次额外行动。
羁绊事件日：当天只能进行羁绊事件，不显示上课、训练、外出、交流。
舞台前夜：独立系统事件日，不占用好感度 80。
First Live：最终演出日。
```

羁绊事件触发逻辑：

```text
当信赖达到 20 / 40 / 60 / 80 阈值时，只标记“羁绊事件已解锁”。
当前这一天不立刻强制打断。
进入下一天时，如果存在未观看的羁绊事件，则当天变成羁绊事件日。
玩家读完羁绊事件并确认后，进入下一天。
```

这样做的好处是：

```text
不会打断当天训练结算。
AI 可以把羁绊剧情写成完整一日或完整半日事件。
每个偶像的主线矛盾有足够篇幅推进。
多出来的 5 天可以补偿羁绊事件占掉的育成时间。
```

### 与手毬路线的关系

手毬特别适合这个机制。

她的好感度 20、40、60 都不是简单的“聊天事件”，而是分别承担：

```text
20：状态下滑与同伴缺位。
40：SyngUp 旧关系与单人偶像训练目标。
60：首场 Live 失败与上限 / 下限问题。
```

这些节点如果硬塞进训练日，会让剧情显得像训练结果的附属品。
如果单独作为羁绊事件日，它们就可以成为真正的角色主线章节。

## 世界书触发建议

阶段人设标签继续使用现有格式：

```text
AFF_TEMARI_20
```

羁绊事件专用种子建议另设触发词，避免和常驻阶段人设混在一起：

```text
BOND_TEMARI_20
BOND_SENA_20
```

后续如果前端支持，可以在羁绊事件 prompt 中额外输出：

```text
羁绊事件标签：BOND_TEMARI_20
```

这样世界书可以分开管理：

```text
AFF_*：关系阶段与常驻人设
BOND_*：某一羁绊事件的剧情大纲、禁忌、原作锚点
```
