# N.I.A 第一轮企划说明设计

## 目标

玩家第一次进入 N.I.A 第一轮企划平板时，由亚纱里老师说明赛制与当前任务。说明是固定教学内容，不请求主 API、不消耗日程节点，并且同一份 N.I.A 存档只播放一次。

## 触发与持久化

- N.I.A 开场剧情完成、企划平板首次收到宿主状态后触发。
- 宿主 N.I.A 状态增加 `firstRoundBriefingSeen`，默认 `false`。
- 玩家看完最后一句后，平板向宿主发送 `niaFirstRoundBriefingComplete`；宿主保存为 `true` 并重新同步状态。
- 已看过、企划已进入后续阶段或当前不是第一轮时不自动播放。

## 呈现

- 对话层位于 `nia-prototype.html` 内，保留桌面和平板作为背景并轻度压暗。
- 使用现有 `assets/novel-standees/asari-sensei.png` 立绘。
- 底部显示亚纱里老师姓名、正文、进度和“继续/明白了”按钮；点击对话框空白区域也可推进。
- 支持键盘 Enter、Space，按钮触控区域不小于 44px；减少动态效果偏好下取消位移动画。

## 固定讲解内容

1. N.I.A 分为三轮，固定审查节点是两次试镜与最终的 FINALE。
2. 试镜和 FINALE 都有粉丝数审查；营业与试镜是主要的粉丝增长来源。
3. 每轮先制定企划，再推进五天日程；训练、营业、外出与制作人工作要共同服务同一条叙事方向。
4. 玩家当前需要阅读咲季档案，填写本轮目标、希望观众看到的形象和实现思路，然后请亚纱里老师完善为可执行的五日计划。

## 验证

- 自动测试覆盖默认状态、状态投影、完成消息持久化、第一轮触发条件、对话结构与固定文案。
- 回归 N.I.A 开场、企划审阅、训练启动和宿主桥接流程。
