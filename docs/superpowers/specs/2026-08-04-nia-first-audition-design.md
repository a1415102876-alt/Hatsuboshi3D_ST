# N.I.A 第一轮试镜设计

> 2026-08-04 最终规则：第一轮只有第 1 名晋级。正式 HUD 横向显示当前前 6 名，第一名使用金色晋级标记，担当偶像使用橙色高亮；四段固定轨迹最终必须到达第 1 名。

## 目标

第一轮试镜以纯文本演出和逐段更新的排行榜呈现培养成果。它不引入音游、卡牌、技能、表现方向选择或 RPG 式战斗。玩家在本轮企划、训练和营业中的决策构成主要玩法，试镜负责把这些成果逐步兑现为舞台表现、分数和名次。

试镜同时是本轮故事的阶段性高潮。它不只证明偶像的能力有所增长，还必须回收此前发生的具体训练、公开营业与制作人关系，使玩家能够辨认舞台上的变化来自哪段培养经历，并由最终表现阶段性回答本轮角色命题。

第一轮定位为海选。全部竞争者使用临时路人，不提前引入正式偶像之间的竞争剧情。

## 基本赛制

- 每场共 8 名参赛者：担当偶像 1 名、临时路人 7 名。
- 只有第 1 名晋级。
- 担当偶像默认以第 1 名晋级，不发生淘汰或整轮重开。
- 排名悬念来自四段演出中的逐步追赶，而不是随机决定最终结果。
- 试镜期间没有制作人临场选项，玩家只需继续观看。

## 四段演出

试镜由四次连续文本生成组成。每段完成后更新一次累计分数与排行榜。

### 第一段：带着本轮经历登台

描写候场、登台、舞台环境和开场表现，建立本场试镜基调。通过一个简短的关系回声表现偶像与制作人在本轮形成的共识，并让尚未解决的短板在开场留下轻微痕迹。担当偶像暂列第 5 名，形成可追赶的初始落后感。此时分数低不代表严重失误，也可以来自部分选手的开场项目先行计分。

### 第二段：训练成果接受检验

具体回收一项主要训练成果。正文必须同时体现训练前的问题、训练中形成的改进，以及改进怎样在当前舞台情境中发挥作用。担当偶像缩小差距并上升至第 4 名。不得只写“训练取得成效”，也不得把 Vo、Da、Vi 或其他数值名称直接写成技能。

### 第三段：企划与营业成果兑现

具体回收一项主要企划或营业成果。评审与观众开始认出本轮企划希望建立的魅力，公开活动中得到确认的公众印象转化为舞台反应和分数。担当偶像上升至第 2 名。允许出现轻量的舞台波动或其他选手表现变化，但不设置玩家选择，也不把普通波动写成严重事故。

### 第四段：角色命题的阶段性回答

最终高光必须回应本轮企划围绕偶像建立的角色命题，而不是随机增加新的魅力或问题。完成高潮、结束动作、评审反应和最终结算后，明确哪些变化已经成为偶像自己的能力，并保留一项尚未解决的短板承接下一轮。担当偶像最终上升至第 1 名。此段必须完整宣布最终分数、最终名次和晋级结果，不能留下新的现场待处理问题。

## 自动叙事回收

玩家不在试镜前选择表现方向或指定回收事件。系统在试镜开始时依据本轮已经发生的事实自动选出回收点，并与选手名单、分数轨迹一起冻结。四段生成期间不得重新筛选。

每场固定选择以下四项：

1. **主要训练成果**：选择与试镜最相关、变化证据最完整的一项训练。必须同时存在训练前问题和训练后改善。
2. **主要企划或营业成果**：选择最能证明本轮企划目标已经得到公开验证的一项成果。优先采用明确的观众、主持人、评审或舆论反馈。
3. **轻量关系回声**：选择制作人与偶像在本轮形成的一句关键指导、一项共识或一个约定。只通过短暂回想、动作习惯、候场交流或演出后的对视呈现，不展开复述整场关系剧情。
4. **未解决短板**：选择一项本轮已经出现、但尚未彻底解决的问题。它可以影响演出过程和最终分数，但不能改变第一名晋级结果。第四段结算后将其作为第二轮的培养起点。

筛选遵循以下优先级：

- 正文中有明确前因、过程和结果的事件，优先于只有状态数值变化的事件。
- 与本轮企划目标和角色命题直接相关的事件，优先于一般日常事件。
- 公开反馈明确的营业，优先于尚未产生结果的计划或申请。
- 同一事件不得同时占用两个主要回收位置。
- 某类没有足够证据时允许留空，禁止编造一段不存在的训练或公开反馈补齐名额。
- 不逐项复述全部日程；一场试镜只突出两个主要回收点、一个轻量关系回声和一个未解决短板。

试镜开始时冻结的数据结构至少包含：

```json
{
  "trainingPayoff": {
    "sourceRef": "day-2-camera-training",
    "before": "面对特写时表情过度用力",
    "gain": "学会通过呼吸放松肩线与笑容",
    "auditionUse": "第二段近景镜头"
  },
  "publicPayoff": {
    "sourceRef": "day-4-online-live",
    "confirmedCharm": "认真好胜时自然流露的可爱反差",
    "auditionUse": "第三段观众反应"
  },
  "relationshipEcho": {
    "sourceRef": "producer-guidance-01",
    "content": "不要把每个表情都做成满分答案",
    "auditionUse": "登台前的短暂回想"
  },
  "remainingWeakness": {
    "sourceRef": "training-risk-perfectionism",
    "content": "过于在意动作是否完美",
    "auditionEffect": "开场略显紧绷，并限制最终分数上限"
  }
}
```

这四项分别映射到第一段的埋设、第二段的训练兑现、第三段的公众印象兑现和第四段的角色回答。AI可以改变具体措辞和镜头呈现，但不能替换来源事实或把尚未解决的短板写成已经完全克服。

## 排行榜

前端冻结 8 名选手的完整排名，正式 HUD 横向显示当前前 6 名，突出担当偶像与当前榜首，并明确标注只有第 1 名晋级。每段结束后，所有选手的累计分数一起变化，不能只有担当偶像增长。

担当偶像的首版固定轨迹为：第 5 名 -> 第 4 名 -> 第 2 名 -> 第 1 名。

轨迹必须满足以下约束：

- 四段累计分数严格递增。
- 最终到达第 1 名。
- 每次名次变化都能由本段演出或其他选手的得分变化解释。
- 不为制造戏剧性而让全部竞争者同时失误。

## 临时路人

进入试镜时，前端一次性生成 7 名路人并冻结至本场结束。每名路人只保存：

```json
{
  "id": "audition-r1-candidate-02",
  "name": "篠原澪",
  "strength": "舞蹈动作干净，开场得分很高",
  "trajectory": "front_runner"
}
```

`trajectory` 从有限曲线池中选择：

- `front_runner`：开场领先，后段增长趋缓。
- `steady`：四段稳定增长，长期处于中上游名次。
- `late_surge`：第三、四段增长明显，制造后程压力。
- `fade_out`：前期较强，后段因普通完成度波动而掉位。
- `average`：表现均衡，作为正常分数参照。

同一场可以重复使用曲线类型，但必须避免七人的分数轨迹完全相同。路人没有完整人设、立绘、关系数据或专属剧情。AI只能依据冻结的姓名、特点和轨迹描写，不得中途替换选手。

## 结果控制

前端在试镜开始时一次性确定第 1 名晋级结果、8 人的四段累计分数和每段排名。AI不负责计算或修改比赛结果，只负责将确定的数据写成连贯演出。

具体分数与奖励仍可由本轮培养总评决定，数值公式等三轮流程全部确定后统一平衡。首版设计只要求输入能够容纳：

- 基础能力与训练成果。
- 本轮企划目标的完成程度。
- 营业成果与已形成的公众印象。
- 体力或稳定性等演出约束。
- 小幅、可复现的稳定波动。

系统采用“先固定第一名结果，再生成合理分数并拆分为四段”的顺序，避免零碎公式意外造成淘汰或不可控的叙事跳变。

## AI 与前端职责

前端固定提供：

- `audition_id`、当前段落编号和本段职责。
- 冻结的 8 人名单与轻量特征。
- 本段开始前和结束后的累计分数、排名及第一名分数。
- 本段需要兑现的培养成果。
- 冻结的自动叙事回收清单及其来源引用。
- 本轮企划目标与需要阶段性回答的角色命题。
- 允许出现的舞台波动。
- 第四段必须完成结算的约束。

AI负责：

- 舞台、镜头、评审和现场反应的具体描写。
- 将能力、训练、企划和公众印象自然转化为舞台表现。
- 让玩家能够从具体动作和现场反应中辨认回收来源，而非直接复述日程摘要。
- 在第四段给出本轮角色命题的阶段性回答，并保留冻结的未解决短板。
- 根据固定分数解释名次变化。
- 保持担当偶像的人设和四段之间的连续性。

AI禁止：

- 自行修改任何分数、排名或晋级结果。
- 生成表现方向选择、技能选择或制作人临场指令。
- 在段落间替换路人名单或重新开始试镜。
- 提前在第一至三段宣布最终结果。
- 在第四段结算后提出新的问题或追加第五段。
- 编造回收清单以外的训练成果、公开反馈或关系进展。
- 把未解决短板写成一次试镜后已经永久解决。

## 结算与持久化

前三段不写入最终履历，不进行重复结算。第四段结束后只结算一次，并保存：

- 担当偶像最终分数和名次。
- 担当偶像最终分数与榜首分数，两者在第四段相同。
- 本场最高光。
- 本场暴露的主要短板。
- 本场实际兑现的训练成果和公开印象来源。
- 本轮角色命题的阶段性回答。
- 第一名晋级对应的粉丝、奖励和下一轮影响。

临时路人默认不写入角色表、关系表或长期 NPC 数据。试镜纪要可以提到特别显眼的选手姓名，但这不自动使其成为正式角色。

## 首版范围

首版只实现第一轮海选的四段演出和排行榜。三轮统一数值公式、第二轮正式竞争者、FINALE 规则以及跨轮奖励平衡不在本设计范围内，待三轮流程全部确定后统一设计。
